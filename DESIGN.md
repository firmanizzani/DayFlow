# Dayflow design system

The supplied prompt pins the visual direction: modern editorial productivity, soft lavender gradients and a premium native mobile experience. Preserve these decisions across every screen.

Plus Jakarta Sans; ink #202138, secondary #62657D for readable small copy, background #F8F9FD, surface #FFFFFF, primary #7366F0, deep indigo #393276. Dark surfaces #131425 and #202139 with lavender #A99BFF. Semantic colors follow prompt.md.

24px page gutters; 4px spacing rhythm; 44px minimum targets. Rounded 20px feature surfaces, 16px form controls. Focus uses an immersive indigo field. Insights uses real backend aggregates only.

Four bottom tabs: Today, Tasks, Calendar, Insights. Profile, task details, planning, recurrence and focus are stack routes. Icons use Lucide. Animations respect reduced motion. Always render loading, empty and recoverable error states.
